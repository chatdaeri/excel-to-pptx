# excel-to-pptx — 엑셀 → PPT 자동 변환 (표 전용 lite)

엑셀 파일을 던지면 한국식 분양/사업 제안서 PPT 가 자동으로 만들어집니다. 표지·목차·간지(챕터 구분 페이지)·표 슬라이드까지 한 번에 들어가고, 표는 PPT 안에서 그대로 편집할 수 있는 진짜 표(이미지가 아니라 표 객체)로 들어갑니다.

---

## 어떻게 사용하나요 (전체 흐름)

1. 엑셀을 아래 약속에 맞춰 준비합니다 (한 번만 익히면 됩니다)
2. AI 한테 "이 엑셀로 제안서 만들어줘" 라고 던집니다
3. AI 가 짧은 주문서를 작성하고 빌드를 돌립니다
4. PPT 파일을 받아서 필요하면 직접 미세 조정합니다

이 스킬은 표 위주의 제안서 전용입니다.

---

## 결과물이 어떻게 생겼나요

- 표지 / 목차 / 간지 / 데이터 슬라이드로 구성 
- 시트 한장 → 슬라이드 한장에 대응
- 시트 한장 당 표가 몇개 있는지에 따라 슬라이드 구성 선택해 자동 제작 (1단 또는 2단)

### 공통 디자인
- 폰트: Pretendard
- 메인 컬러: 네이비 #00205F (작은제목 박스, 컬럼 헤더 막대)
- 강조 컬러: 빨강 #C0392B (강조 행 외곽선·텍스트)
- 표 헤더 배경: 회색 #E8E8E8
- 표 첫 컬럼 배경: 연파랑 #EAEFF8
- 슬라이드 비율: 16:9

디자인을 바꾸고 싶다면 "스타일 바꾸기" 안내를 보세요.

---

## 엑셀을 어떻게 준비하면 되나요

본인이 평소 쓰던 엑셀에 몇 가지 약속만 지켜서 작성하면 됩니다. 

### 시트 한 장이 슬라이드 한 장이 됩니다

표지·목차·간지는 엑셀과 무관하게 AI 가 따로 만들어주기 때문에, 엑셀에는 **데이터 슬라이드만** 신경 쓰면 됩니다.

### 시트 이름 짓는 법

시트명은 PPT 위쪽에 자동으로 표시되는 "Ⅰ. 사업개요" 같은 라벨로 변환됩니다. 그래서 **번호와 키워드를 언더스코어(`_`)로 구분**해서 짓는 게 좋습니다.

```
01_사업개요              → "Ⅰ. 사업개요"
02_시장환경_거래량       → "Ⅱ. 시장환경 / 거래량"
03_입지평가              → "Ⅲ. 입지평가"
```

### 시트 안의 행 구조 

시트 안에서 위쪽 두 행은 메시지 자리, 그 아래로는 표 데이터 자리입니다.

**1행 (A1 셀) — 메인 메시지**
슬라이드 가운데 큼지막하게 들어갈 한 줄 결론입니다. 예: "광주 주요 지역 시세 상승세", "군포 당동 오피스텔 사업지 핵심 정보". 너무 길면 화면이 좁아지니 한국어 25자 안팎이 좋습니다.

**2행 (A2 셀) — 부제**
메인 메시지 위에 작게 들어갈 설명. 메인 메시지를 한 단계 풀어주는 문장이에요. 예: 메인이 "광주 주요 지역 시세 상승세" 라면 부제는 "동구·서구 동반 상승" 같은 식. 비워둬도 빌드는 되지만, 비어 있으면 슬라이드 위쪽이 좀 허전합니다.

**3행 — 빈 행 한 줄**
메시지와 표를 분리하는 신호입니다. 한 칸 비워 두세요.

**4행부터 — 표 블록**
아래에서 따로 설명합니다.

### 표 블록 적는 법

표 블록은 세 부분으로 구성됩니다.

```
A4: [표] 사업지 개요                            ← 블록 제목
A5: 구분        | 내용         | 구분    | 내용     ← 헤더 행
A6: 대지위치    | 경기 군포시  | 용도지역 | 준주거지역 ← 데이터 행
A7: 대지면적    | 1,234 ㎡     | 연면적   | 8,765 ㎡  ← 데이터 행
... (필요한 만큼)
A11: [출처: 사업계획서]                         ← 출처 (선택)
```

**블록 첫 행 — `[표]` 로 시작하는 제목**
A열에만 값을 쓰고 나머지는 비워 둡니다. **반드시 `[표]` 로 시작**해야 파일을 읽는 도구가 "여기 표가 있구나" 하고 알아챕니다. `[표]` 뒤에 적은 제목은 PPT 표 위쪽에 들어갑니다 (예: "사업지 개요" 같은 표의 제목).

**그 다음 행 — 헤더**
표의 컬럼 이름들. 회색 배경에 굵은 글씨로 들어갑니다.

**그 아래 — 데이터 행**
원하는 만큼 적으면 됩니다. 첫 번째 컬럼은 자동으로 연한 파란 배경 + 굵은 글씨가 입혀져요. 그래서 첫 컬럼에 "구분"·"항목명" 같은 라벨을 넣고 두 번째 컬럼부터 값을 적는 패턴이 잘 어울립니다.

**(선택) 마지막 행 — 출처**
A열에만 `[출처: 부동산114]` 같은 형식으로 적으면 슬라이드 맨 아래 작은 회색 글씨로 들어갑니다. 안 적어도 되지만, 데이터 슬라이드는 출처를 적어주는 게 일반적이에요.

### 표를 두 개 나란히 두려면

한 시트에 표 블록을 두 개 넣으면 자동으로 좌·우 2단 슬라이드가 됩니다. 두 블록 사이에는 **빈 행을 한 줄** 두세요.

```
A1: 인근 단지 시세 대비 본 사업지 경쟁력 우위
A2: 동일 평형대 5~10% 저렴
(A3 빈 행)
A4: [표] 주변 단지 시세
A5: 단지 | 평형 | 시세
A6: A단지 | 24평 | 4.5억
A7: B단지 | 24평 | 4.8억
A8: C단지 | 34평 | 6.2억
(A9 빈 행)
A10: [표] 본 사업지 분양가 (안)
A11: 타입 | 공급 | 분양가
A12: 24A | 60   | 4.6억
A13: 24B | 40   | 4.7억
A14: 34  | 20   | 6.0억
A15: [출처: 부동산 R114]
```

좌측엔 "주변 단지 시세" 표, 우측엔 "본 사업지 분양가" 표가 나란히 들어갑니다.

### 셀 병합은 엑셀에서 평소처럼

표 안에서 헤더를 가로로 묶거나, 같은 값이 여러 행에 걸쳐 있을 때 **엑셀에서 그냥 평소처럼 셀 병합**을 해 두세요. 이 스킬이 엑셀의 병합 정보를 읽어서 PPT 표에도 동일하게 병합을 재현해 줍니다. 병합된 셀의 테두리도 깔끔하게 정리돼서 들어갑니다.

### 강조 행 — 한 줄 빨갛게 띄워주기

특정 행을 시각적으로 강조하고 싶을 때 (예: 합계 행, 추천 옵션 행) 강조될 행 번호를 AI 한테 같이 알려 주세요. AI 가 주문서에 반영해 줍니다. "주변 단지 시세 표에서 4번째 행을 강조해줘" 식으로 말씀하시면 됩니다. 강조된 행은 빨간 굵은 외곽선이 둘러지고 글자도 빨간 굵은 글씨로 바뀝니다.

## 스타일 바꾸기

기본 톤은 (네이비 박스 + 회색 표 헤더 + Pretendard 폰트) 로 고정돼 있습니다. 스타일 가이드가 따로 있다면 이 스킬에 스타일만 바꿔서 계속 쓰는 방식이 가능합니다.

### 어떻게 요청하면 되나요

스타일을 적용할 PPTX 파일을 AI 한테 던지면서 다음과 같이 말씀하시면 됩니다.

> "우리 회사 PPT 인데, 이 톤에 맞게 lite 스킬 스타일을 바꿔줘"

PPTX 파일을 받는 게 가장 좋습니다. 이미지 파일(JPG/PNG)도 가능하지만, PPTX 안에는 정확한 색깔 코드와 폰트 이름이 들어 있어서 AI 가 추측 없이 정확하게 분석할 수 있어요.

### 그 다음에 일어나는 일

1. **AI 가 PPTX 를 분석합니다** — 컬러·폰트·표 헤더 색·표지 배경 등을 추출
2. **변경할 항목 목록을 보여드립니다** — "메인 컬러 #00205F → #1A4D8C, 표 헤더 배경 회색 → 네이비, 폰트 Pretendard → Noto Sans KR ..." 식으로
3. **컨펌 (또는 부분 수정 요청)** — 일부만 마음에 안 들면 짚어 주세요
4. **AI 가 실제로 스킬 코드를 수정** — `_helpers.cjs`, `t3-divider.cjs`, `t5-cover-toc.cjs` 같은 파일의 색·폰트 값만 교체
5. **간단한 테스트 빌드** — 결과 PPT 한 장 만들어서 톤이 잘 바뀌었는지 확인

한 번에 완벽하게 맞기보다는 1~2번 추가 조정이 들어가는 게 보통입니다. 표 헤더 글씨 크기, 디바이더에 회사 로고 추가, 색깔 미세 조정 같은 것들이요.

### 바꿀 수 있는 것

- 컬러 (메인 네이비 / 강조 빨강 / 표 헤더 / 좌측 라벨 / 출처 회색 등)
- 폰트 (Pretendard 외에 Noto Sans KR, 자체 회사 폰트 등 — Static 폰트만 가능)
- 표 헤더 배경/글씨 색
- 표 외곽선 굵기, 내부선 표시 여부
- 강조 행 처리 방식 (빨간 외곽선 → 배경색 등)
- 작은제목 박스 모양 (네이비 사각 박스 → 밑줄/수직 막대/연한 배경 등)
- 표지·간지 배경 (단색 → 이미지/그라데이션, 회사 로고 추가)
- 출처 위치·크기·정렬

### 바꿀 수 없는 것

- 슬라이드 종류 자체 (표지·목차·간지·풀폭표·2단표 5종 고정)
- 차트 (이 스킬은 차트 자체가 없음)
- 헤더 영역의 4단 구조 (대제목 / 작은제목 / 부제 / 메인 메시지). 각 요소 스타일은 자유롭게 바꿔도 4단으로 쌓이는 구조 자체는 한국식 분양 제안서의 정체성이라 유지됩니다.

### 한 가지 주의

이 변경은 **이 스킬 자체** 의 기본 톤을 바꾸는 작업이라, 한 번 바꾸면 그 다음부터는 모든 PPT 가 회사 톤으로 빌드됩니다. 만약 회사 A 톤과 회사 B 톤을 둘 다 써야 한다면 스킬 폴더를 통째로 복사해서 두 개로 나눠두는 방법이 있어요. AI 한테 그렇게 분리해 달라고 요청하시면 됩니다.
