# excel-to-pptx — 엑셀 → PPT 자동 변환 (표 전용 lite)

엑셀 파일을 던지면 한국식 분양/사업 제안서 PPT 가 자동으로 만들어집니다. 표지·목차·간지(챕터 구분 페이지)·표 슬라이드까지 한 번에 들어가고, 표는 PPT 안에서 그대로 편집할 수 있는 진짜 표(이미지가 아니라 표 객체)로 들어갑니다.

---

## 어떻게 사용하나요 (전체 흐름)

1. 엑셀을 아래 약속에 맞춰 준비합니다 (한 번만 익히면 됩니다)
2. AI 한테 "이 엑셀로 제안서 만들어줘" 라고 던집니다
3. AI 가 짧은 주문서를 작성하고 빌드를 돌립니다
4. PPT 파일을 받아서 필요하면 직접 미세 조정합니다

이 스킬은 표 위주의 제안서 전용입니다.

---

## 결과물이 어떻게 생겼나요

- 표지 / 목차 / 간지 / 데이터 슬라이드로 구성 
- 시트 한장 → 슬라이드 한장에 대응
- 시트 한장 당 표가 몇개 있는지에 따라 슬라이드 구성 선택해 자동 제작 (1단 또는 2단)

### 공통 디자인
- 폰트: Pretendard
- 메인 컬러: 네이비 #00205F (작은제목 박스, 컬럼 헤더 막대)
- 강조 컬러: 빨강 #C0392B (강조 행 외곽선·텍스트)
- 표 헤더 배경: 회색 #E8E8E8
- 표 첫 컬럼 배경: 연파랑 #EAEFF8
- 슬라이드 비율: 16:9

디자인을 바꾸고 싶다면 "스타일 바꾸기" 안내를 보세요.

---

## 엑셀을 어떻게 준비하면 되나요

**템플릿 파일을 받아서 그대로 쓰시면 됩니다.** 셀 안에 "여기엔 이걸 적으세요" 식으로 설명이 다 들어 있으니, 내 데이터로 교체만 하면 끝.

### 템플릿 받기

👉 [`examples/sample-template.xlsx`](examples/sample-template.xlsx)

### 기본 규칙 세 줄 요약

- **시트 하나 = 슬라이드 한 장.** 시트를 추가할수록 슬라이드도 늘어납니다
- **한 시트에 표 1~2개 권장.** 3개 이상이면 시트를 나누세요
- **시트 이름은 `01_대목차_소목차` 패턴 권장.** 규칙 안 지켜도 빌드는 되지만, 지키면 슬라이드 위쪽 라벨이 깔끔하게 뽑힙니다

### 작성 팁

- 표지·목차·간지는 AI 가 따로 만들어줍니다 — 엑셀엔 **표 데이터만** 담으면 됨
- **메인·서브 메시지가 생각 안 나면 그냥 비워두세요** — AI 가 표 내용 보고 알아서 써줍니다
- **셀 병합은 엑셀에서 평소처럼** 하세요. PPT 표에 그대로 재현됩니다
- **강조하고 싶은 행**이 있으면 AI 한테 "N번째 행 강조해줘" 라고 하시면 빨간 외곽선으로 처리됩니다

## 스타일 바꾸기

기본 톤은 (네이비 박스 + 회색 표 헤더 + Pretendard 폰트) 로 고정돼 있습니다. 스타일 가이드가 따로 있다면 이 스킬에 스타일만 바꿔서 계속 쓰는 방식이 가능합니다.

### 어떻게 요청하면 되나요

스타일을 적용할 PPTX 파일을 AI 한테 던지면서 다음과 같이 말씀하시면 됩니다.

> "우리 회사 PPT 인데, 이 톤에 맞게 lite 스킬 스타일을 바꿔줘"

PPTX 파일을 받는 게 가장 좋습니다. 이미지 파일(JPG/PNG)도 가능하지만, PPTX 안에는 정확한 색깔 코드와 폰트 이름이 들어 있어서 AI 가 추측 없이 정확하게 분석할 수 있어요.

### 그 다음에 일어나는 일

1. **AI 가 PPTX 를 분석합니다** — 컬러·폰트·표 헤더 색·표지 배경 등을 추출
2. **변경할 항목 목록을 보여드립니다** — "메인 컬러 #00205F → #1A4D8C, 표 헤더 배경 회색 → 네이비, 폰트 Pretendard → Noto Sans KR ..." 식으로
3. **컨펌 (또는 부분 수정 요청)** — 일부만 마음에 안 들면 짚어 주세요
4. **AI 가 실제로 스킬 코드를 수정** — `_helpers.cjs`, `t3-divider.cjs`, `t5-cover-toc.cjs` 같은 파일의 색·폰트 값만 교체
5. **간단한 테스트 빌드** — 결과 PPT 한 장 만들어서 톤이 잘 바뀌었는지 확인

한 번에 완벽하게 맞기보다는 1~2번 추가 조정이 들어가는 게 보통입니다. 표 헤더 글씨 크기, 디바이더에 회사 로고 추가, 색깔 미세 조정 같은 것들이요.

### 바꿀 수 있는 것

- 컬러 (메인 네이비 / 강조 빨강 / 표 헤더 / 좌측 라벨 / 출처 회색 등)
- 폰트 (Pretendard 외에 Noto Sans KR, 자체 회사 폰트 등 — Static 폰트만 가능)
- 표 헤더 배경/글씨 색
- 표 외곽선 굵기, 내부선 표시 여부
- 강조 행 처리 방식 (빨간 외곽선 → 배경색 등)
- 작은제목 박스 모양 (네이비 사각 박스 → 밑줄/수직 막대/연한 배경 등)
- 표지·간지 배경 (단색 → 이미지/그라데이션, 회사 로고 추가)
- 출처 위치·크기·정렬

### 바꿀 수 없는 것

- 슬라이드 종류 자체 (표지·목차·간지·풀폭표·2단표 5종 고정)
- 차트 (이 스킬은 차트 자체가 없음)
- 헤더 영역의 4단 구조 (대제목 / 작은제목 / 부제 / 메인 메시지). 각 요소 스타일은 자유롭게 바꿔도 4단으로 쌓이는 구조 자체는 한국식 분양 제안서의 정체성이라 유지됩니다.

### 한 가지 주의

이 변경은 **이 스킬 자체** 의 기본 톤을 바꾸는 작업이라, 한 번 바꾸면 그 다음부터는 모든 PPT 가 회사 톤으로 빌드됩니다. 만약 회사 A 톤과 회사 B 톤을 둘 다 써야 한다면 스킬 폴더를 통째로 복사해서 두 개로 나눠두는 방법이 있어요. AI 한테 그렇게 분리해 달라고 요청하시면 됩니다.
